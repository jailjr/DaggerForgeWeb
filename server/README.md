# Local API

Run with `node server/index.js`. The API uses a transactional temp-file rename for the local demo store at `data/campaigns.json`; `data/` is ignored by Git. It exposes campaign creation, player-token participant joins, campaign-scoped views, GM-only audit events, character creation/claims, versioned updates, mode changes, participant nickname/revocation, announcements, custom library content, player-access regeneration, secret-free export/import, and Server-Sent Events.

Set `SERVE_STATIC=1` after `npm run build` to serve the compiled frontend from the same process. `CORS_ORIGIN` should be set to the exact HTTPS frontend origin in production. The file-backed adapter is suitable for local development and smoke testing. For production, replace the repository functions with Postgres transactions and store only token hashes. The authorization and response-shaping rules in this adapter are the required behavior: unauthorized resources return 404 where possible, player projections exclude GM library/private notes, and character updates require an expected version.
